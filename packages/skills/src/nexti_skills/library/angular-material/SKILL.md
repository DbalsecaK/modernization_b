- Standalone components and signals for local state.
- Typed reactive forms whose validators mirror the rules of the spec.
- Angular Material components themed through design tokens.
- Lazy-loaded routes; an HTTP client generated from the OpenAPI document.
- Accessibility: a label for every control, focus management with the CDK a11y utilities.
